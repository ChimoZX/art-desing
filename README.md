#  Bakery Frontend Concept

A modern frontend concept for an artisan bakery, built entirely with React, TypeScript, Tailwind CSS, and Vite. I originally built this as a template for freelance gigs.

The main goal was to build a UI that doesn't just look good, but feels fluid and responsive, bringing it all to life with Framer Motion for the animations and micro-interactions.

**[ View Live Demo ](https://art-dulce.vercel.app/)**


###  Tech Stack
* **React** — UI components
* **TypeScript** — Strong typing and maintainable code
* **Tailwind CSS** — Utility-first styling
* **Framer Motion** — Fluid animations and page transitions
* **Vite** — Frontend tooling and development server

###  Run it locally

```bash
# Clone the repo
git clone [https://github.com/ChimoZX/NOMBRE-DE-TU-REPO-AQUI.git](https://github.com/ChimoZX/NOMBRE-DE-TU-REPO-AQUI.git)

# Go into the project
cd NOMBRE-DE-TU-REPO-AQUI

# Install dependencies
npm install

# Start the dev server
npm run dev
